# 行首误标、空心和弦漏标与右侧排版设计

## 目标

修复用户提供的三类真实谱面问题：

1. 每个谱表行左侧的行号、谱号、调号、拍号等符号不生成简谱标注。
2. 小尺寸空心音符及同一和弦中的多个空心音符能够被检测并标注。
3. 标注列上下空间不足时，只要右侧存在完整空位，就在右侧显示，而不是挤在音符下方或被裁切。
4. 音符上方存在完整空位时必须放在上方，不得直接放到下方。

继续采用保守识别策略，不以强制符干证据删除真实音符，不接入大模型或外部 API。

## 行首符号区

从五线谱灰度线条估算每个谱表的左边界。以谱线间距为尺度，在左边界右侧划定有限的谱号/调号/拍号区域；区域内的候选不进入音符标注。该边界按每个 `Staff` 独立计算，避免页面行号或大括号影响其他谱表。

过滤必须有最大宽度限制，不延伸到首个正常小节内容，优先避免删除紧靠行首的真实音符。

## 空心音符

`detect_hollow_heads` 接收谱线间距 `s`，用相对尺寸和面积筛选封闭白洞，替代固定像素阈值。候选随后继续通过 `_is_real_notehead` 的封闭性检查和谱表纵向范围检查。

同一黑色外轮廓中存在多个独立白洞时，每个洞分别产生一个空心音符头，并由 `build_chords` 合并成和弦事件。

## 右侧排版

排版顺序统一为：

1. 从音符正上方开始，在允许的上方区域内搜索完整空位；
2. 只有上方区域全部不可用时，低音谱才尝试谱表下方；
3. 上下都不可用时，从音符右侧搜索；
4. 所有标准候选都无效时使用图内兼容位置。

因此，只要上方存在有效候选，就不得选择下方。右侧搜索从最小安全距离开始，按小步长向右进行。每个候选都必须：

- 完整位于图片内；
- 不覆盖原谱黑色像素；
- 不覆盖已绘制简谱；
- 保持和弦数字列的顺序及完整边界。

找到第一个有效横向位置即停止；只有右侧所有候选都无效时，才使用现有图内兼容位置。

## 测试

- 行首区域中的多个不同形状候选全部移除，边界外首个真实音符保留；
- 不同谱表分别计算行首区域；
- 小谱距空心音符能够检测；
- 同一和弦的两个空心洞均检测并合并；
- 固定的第一个右侧位置受阻、稍远右侧为空时继续向右并成功绘制；
- 右侧无完整空间时保持图内兼容回退；
- 上方近处受阻但稍远处存在空间时继续向上搜索，不得绘制到下方；
- 上方第一个候选可用时始终优先于下方和右侧；
- 现有连续重复去重和排版测试全部通过；
- 至少一张用户真实谱面端到端生成可读取结果。
